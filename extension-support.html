1. Quick start

  1. Open the regular webpage where you want to use the teleprompter.
  2. Select the See Through Script Reader icon in your browser toolbar.
  3. Write, paste, or choose a saved script.
  4. Select Start Prompter.
  5. Move the overlay using its top bar, resize it from the marked bottom-right grip, then adjust speed, text size, and brightness as needed.
Tip: Open the extension from the actual calling, recording, or presentation page you plan to use. This gives the extension temporary access to that selected tab.

2. Supported pages

The prompter works on regular web pages that use an http:// or https:// address, including many browser-based video-call, webcam-recording, livestreaming, presentation, and teaching services.

Browsers prevent extensions from running on certain protected pages. The prompter cannot open on browser settings, extension-management pages, new-tab pages, browser-store listings, or other internal addresses such as chrome://, edge://, and about: pages. Some built-in PDF viewers and restricted websites may also block injection.

Browser-specific notes

  • Google Chrome: Use the extension on normal websites. Chrome system pages, the Chrome Web Store, and chrome:// addresses do not allow the overlay.
  • Microsoft Edge: Use the extension on normal websites. Edge system pages, Microsoft Edge Add-ons pages, and edge:// addresses do not allow the overlay.
  • Mozilla Firefox: The current edition requires Firefox 142 or later. Firefox system pages, Firefox Browser Add-ons pages, and internal about: addresses do not allow the overlay.

3. Using the full-page editor

Select Full editor from the popup when you need more writing space. The full editor includes your searchable script library, performance cues, word and character counts, automatic local saving, and a vertically resizable writing area.

If the editor says “No webpage selected”

Return to the webpage where you want the prompter, open the extension popup there, and select Full editor again. Opening the editor directly does not select a target page. If the original page was closed or replaced, reopen the editor from the new target tab.

Resize the writing area

Drag the Drag to resize handle along the lower edge of the editor. The chosen height is remembered locally. Double-click the handle to return to the responsive default height. When the handle is focused, the arrow and Page Up or Page Down keys can also resize it.

4. Floating prompter controls

  • Play or Pause: Start or suspend automatic scrolling.
  • Restart: Return to the beginning of the script.
  • Speed: Adjust scrolling from a slow 0.2× pace up to 5×.
  • Text size: Make the script easier to read at your chosen distance.
  • Brightness: Change the darkness of the overlay background while keeping the webpage visible behind it.
  • Manual scrolling: Use the mouse wheel or scrollbar while Play remains active. Automatic scrolling resumes from the position you selected.
  • Minimize: Collapse the prompter into a compact draggable pill. Select the plus button to restore it.
  • Resize: Drag the highlighted diagonal grip in the lower-right corner.

5. Video calls, recordings, and screen sharing

The extension places the script above the webpage on your screen. It does not add the text to your webcam feed, activate your camera or microphone, or modify the video produced by your camera.

Screen-sharing reminder: If you share or record your entire screen or the browser tab containing the prompter, the overlay may be visible in that shared or recorded view. Share only the appropriate window, tab, or camera feed when the script must remain private.

For the most natural eye line, position the prompter close to the webcam preview or camera indicator and use a comfortable text size with moderate scrolling speed.

6. Saved scripts and performance cues

Scripts, titles, the selected script, and editor preferences are saved in the browser’s local extension storage. The popup and full editor use the same script library.

Use the built-in cue buttons or create a custom direction. A cue is stored in the script using the format [CUE: Pause] and appears as a distinct direction marker in the running prompter. Ordinary bracketed text remains unchanged.

Uninstalling the extension or clearing its extension data may remove locally saved scripts. Copy important scripts into another document if you need a separate backup.

7. Troubleshooting

“Open a regular webpage first”

The active tab is a protected browser page or another unsupported address. Switch to the calling, recording, presentation, or other normal website, then open the extension again.

The prompter does not appear

  • Confirm that the current address begins with http:// or https://.
  • Refresh the webpage and select Start Prompter again.
  • Close an older prompter before starting a new one.
  • Make sure the extension is enabled and updated in your browser’s extension manager.
  • Try another regular webpage to determine whether the original website restricts extensions.

Manual scrolling seems to jump back

Use the latest extension version. Current builds hand control to the mouse wheel or scrollbar and resume automatic scrolling from the manually selected position.

The controls are crowded

Widen the overlay using the bottom-right resize grip. At narrow widths, controls switch to a compact responsive layout.

The prompter disappeared in fullscreen

Exit fullscreen, start the prompter again, and then re-enter the webpage’s supported fullscreen mode. Browser-level or operating-system fullscreen behavior can vary by website and browser.

Firefox compatibility

The current Firefox edition supports Firefox 142 and later. Update Firefox if the add-on cannot be installed or enabled.

8. Privacy and permissions

The extension has no account system, analytics, advertising, tracking, or cloud backend. Scripts and settings stay in the browser’s local extension storage and are not transmitted to Coinimain.

The storage permission provides the local script library. The activeTab and scripting permissions are used after you choose Start Prompter to place the packaged overlay on the selected webpage.

Read the complete browser extension privacy policy.

For a faster diagnosis, include:

  • Your browser name and version
  • The extension version
  • The type of website where the problem occurred
  • The steps that reproduce the issue
  • A screenshot, if it does not reveal private information

Do not send confidential scripts, passwords, call details, or other sensitive information.
