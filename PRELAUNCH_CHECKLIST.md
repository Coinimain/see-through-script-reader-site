# Prelaunch checklist

## Website

- [ ] Proofread homepage, About, Support, Privacy, and Terms pages
- [ ] Confirm public developer/provider name
- [ ] Confirm support email
- [ ] Confirm package name
- [ ] Update effective dates
- [ ] Test every internal link on mobile and desktop
- [ ] Test the support email link
- [ ] Publish GitHub Pages
- [ ] Confirm privacy URL opens without signing in
- [ ] Confirm the privacy page is not a PDF

## Android app

- [ ] Add Privacy Policy row in Settings
- [ ] Open the published privacy URL from the app
- [ ] Add Terms of Use row if desired
- [ ] Confirm app version and package name
- [ ] Export/import test with several scripts
- [ ] Test overlay permission on multiple Android versions
- [ ] Test update installation without losing scripts
- [ ] Create and securely back up the release keystore

## Google Play

- [ ] Add homepage or support URL
- [ ] Add privacy-policy URL
- [ ] Complete Data safety accurately
- [ ] Declare no ads for the initial no-ad release
- [ ] Complete content rating and app-access sections
- [ ] Replace the website’s coming-soon button after listing is live

## Before adding ads later

- [ ] Choose advertising provider
- [ ] Review SDK data collection
- [ ] Update privacy policy before release
- [ ] Update Data safety before release
- [ ] Change Play declaration to Contains ads
- [ ] Add `app-ads.txt` if required
- [ ] Keep ads out of the active teleprompter and recording workflow
